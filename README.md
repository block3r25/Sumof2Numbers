# Simple Sum Calculator

A simple application that computes the **sum of two numbers**. This project is intended as a basic example for learning programming fundamentals, input handling, arithmetic operations, and GitHub project management.

## Features

- Accepts two numbers as input
- Computes their sum
- Displays the calculated result
- Simple and easy-to-understand implementation

## How It Works

The application uses the basic addition operation:

```text
Sum = Number 1 + Number 2
```

### Example

```text
Enter first number: 15
Enter second number: 25

Sum: 40
```
